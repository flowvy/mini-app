# Список изменений

Release notes Flowvy описывают пользовательский результат и итоговую разницу с предыдущим stable
release. Версии, даты, порядок категорий и число пунктов должны совпадать с `CHANGELOG.md`.

## Unreleased

Переносите проверенные пункты в `## X.Y.Z — YYYY-MM-DD` только после согласования release version.
Используйте лишь категории `Новое`, `Улучшения`, `Исправления` и `Безопасность` в этом порядке;
пустые категории пропускайте.
