# 0005: Open-source лицензия и граница бренда

Status: accepted
Date: 2026-08-27
Owners: Flowvy

## Context

Flowvy Mini App готовится к публикации как open-source self-hosted приложение. Его backend работает
по сети и может быть развёрнут сторонним оператором без распространения бинарной копии. Permissive
лицензия позволила бы запустить изменённый закрытый сервис без возврата изменений в проект.

Repository также содержит название и визуальную айдентику Flowvy, промоизображения, сторонние
шрифты и адаптированные service icons. Лицензия кода не должна создавать впечатление, что любой форк
является официальным Flowvy, и не должна стирать обязательную third-party attribution.

## Decision

1. Собственный исходный код Flowvy публикуется по `GNU Affero General Public License v3.0 only`
   (`SPDX-License-Identifier: AGPL-3.0-only`). Root [`../../LICENSE`](../../LICENSE) содержит
   неизменённый официальный текст GNU AGPLv3.
2. Выбирается только версия 3, без автоматического разрешения применять будущую версию лицензии.
3. Изменённая версия, с которой пользователи взаимодействуют по сети, должна предоставлять им
   соответствующий исходный код на условиях AGPLv3.
4. Название Flowvy, логотип, фирменный стиль и промоизображения не лицензируются по AGPL. Правдивое
   упоминание оригинального проекта разрешено, но изменённые дистрибутивы должны быть переименованы и
   не могут создавать впечатление официальной версии. Полная граница описана в
   [`../../TRADEMARKS.md`](../../TRADEMARKS.md).
5. Сторонние материалы сохраняют собственные лицензии и attribution. Их централизованный список
   находится в [`../../THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md); локальные license
   files, например font OFL, остаются рядом с соответствующими материалами.
6. Package metadata frontend и backend использует SPDX expression `AGPL-3.0-only`.

## Alternatives

- **MIT** — отклонена: разрешает закрыть изменения и эксплуатировать их как сетевой сервис без
  публикации source code.
- **Apache-2.0** — отклонена по той же причине; явный patent grant полезен, но не компенсирует
  отсутствие network copyleft для выбранной модели проекта.
- **GPL-3.0-only** — отклонена: обычная GPL не закрывает случай, когда изменённый backend доступен по
  сети, но его копия не распространяется.
- **Проприетарная или source-available лицензия** — отклонена: противоречит решению публиковать
  Flowvy как open-source проект.
- **AGPL-3.0-or-later** — отклонена: автоматический переход на ещё не рассмотренные будущие условия
  лицензии не нужен.

## Consequences

- Коммерческое использование, модификация и самостоятельный hosting разрешены при соблюдении AGPL.
- Операторы изменённых сетевых версий обязаны дать их пользователям доступ к соответствующему
  исходному коду.
- Форки должны отделить собственную айдентику от бренда Flowvy, даже если код остаётся под AGPL.
- Attribution сторонних материалов становится частью review при добавлении или замене bundled
  assets.
- Этот ADR фиксирует принятое product decision, но не заменяет профессиональную юридическую
  консультацию для конкретной юрисдикции или спорного использования бренда.

## Verification and rollout

- Root `LICENSE` сравнивается с официальным `https://www.gnu.org/licenses/agpl-3.0.txt`.
- `frontend/package.json` и `backend/pyproject.toml` содержат `AGPL-3.0-only`.
- Repository Markdown link check охватывает README, trademark policy, notices и этот ADR.
- Перед переключением repository visibility проводится отдельный review tracked files и Git
  history на secrets, private identifiers и production configuration.
